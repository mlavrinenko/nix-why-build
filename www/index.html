nix-why-build

Your nixos-rebuild is compiling Firefox again. Why? nix build --dry-run won't tell you. It only lists what's missing from your store, so anything you built yesterday quietly drops off the list.

nix-why-build asks the binary caches instead. It stops wherever a cache serves the output, the same cut nix makes on an empty store. Same answer on your laptop and on a fresh box.

Try it

No install needed. Point it at your flake.

nix run github:mlavrinenko/nix-why-build -- .#nixosConfigurations.<host>

What you get

A trimmed report, cut from a real run on my desktop. The ... lines are the groups I skipped.

llama-cpp-0.5.0

11 local-only: cuda-merged-12.9, gimp-with-plugins-3.0.8, krita-6.0.2.1 (+8 more)
  why local-only: allowSubstitutes = false: nix builds it even when a cache has it
523 roots in 29 groups, 52 packages to build, 1621 more without a pname

A root is something no cache serves even though everything it needs is served. That's where the miss starts. Fix the root and everything it drags in comes from the cache again. Roots that drag in the same packages print as one group, so 246 downloads cost one line.

wanted by names the options that pull a root in and the module files that set them. Yours print as apps/llama-cpp-16gb.nix, a flake input's as home-manager:modules/....

Why no cache has it

why compares each root with what nixpkgs builds under the same attribute, in every nixpkgs input of your flake.

whymeans
local-onlyallowSubstitutes = false, so nix builds it even when a cache has it
fetcha fixed-output download no cache has; the build fetches it
overriddendiffers from nixpkgs' own; the diff names the attributes and inputs
unfreeidentical to nixpkgs', which Hydra skips as unfree
not-built-by-hydraidentical, but meta.broken or meta.hydraPlatforms keeps Hydra off it
newer-than-cacheidentical, and that nixpkgs' hello isn't cached either
no-counterpartno nixpkgs attribute matches its pname (it says what it tried)
unknownnone of the above could be shown, and it says why

It never guesses. No evidence, no category.

Install

Run it straight from the flake, or put it on your PATH.

nix run github:mlavrinenko/nix-why-build -- .#nixosConfigurations.<host>
cargo install nix-why-build

Every release also lands on crates.io and as a binary on the releases page. The README has the rest, like --json output and the Rust library.
